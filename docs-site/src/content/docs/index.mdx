## Place a call with an AI agent on it

```bash
curl -X POST https://your-openline.example/v1/calls \
  -H "Authorization: Bearer $OPENLINE_KEY" -H "content-type: application/json" \
  -d '{"deviceId":"phone-7f3a91c2","to":"+919876543210",
       "stream":{"url":"wss://my-agent.example.com/ws","format":"twilio"}}'
```

When the call is answered, OpenLine opens your agent's WebSocket and streams the conversation
both ways. Your agent hangs up by closing the socket.

## Why OpenLine

- **A self-hosted Twilio alternative** for voice: the same building blocks (calls API, status
  webhooks, media streams), running on hardware you own.
- **Built for AI agents:** Pipecat, LiveKit workers or your own speech pipeline get raw 16 kHz
  PCM or Twilio-compatible audio.
- **Local numbers:** calls come from a real local SIM, so they look like any other call.
